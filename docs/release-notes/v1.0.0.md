# AstroManager v1.0.0 — First Public Release

AstroManager v1.0.0 is the first public release. Plan astrophotography sessions
around target visibility, astronomical darkness, Moon conditions and the
forecast for your observing site. The built-in target catalog and core planning
tools work offline. The app is available in English and German.

## Highlights

- Explore the built-in catalog and get target recommendations based on
  visibility, Moon conditions, cloud cover and the optional Bortle class you
  enter for your site.
- Use the Night Planner to see the darkness window and schedule project targets
  on an editable timeline.
- Explore the Sky Atlas with catalog details, a live field-of-view readout and
  camera framing in Detail and Sky Dome modes.
- Customize the Dashboard and refresh the 7-Night Forecast on demand. Switch
  between clear-sky summaries for astronomical darkness and the full local day.
- Manage observing sites, equipment, imaging projects and session logs. Save
  terrain horizons where elevation data is available, and export or restore
  `.ambackup` files with optional session images.

## Download and install

| Platform | How to get AstroManager |
| --- | --- |
| Android | Download the signed APK from the release assets. |
| Windows | Download the portable x64 ZIP, extract it in full and run `astromanager.exe`. |
| macOS | Download the macOS ZIP, extract it and move `AstroManager.app` to Applications. See the [first-launch steps for the unnotarized build](https://github.com/CodefrogCF/AstroManager/blob/main/docs/installation.md#first-launch-on-macos). |
| iOS | Build and install on your own iPhone with Xcode and a free Apple Account. [English instructions](https://github.com/CodefrogCF/AstroManager/blob/main/docs/installation.md#build-for-your-iphone) · [Deutsche Anleitung](https://github.com/CodefrogCF/AstroManager/blob/main/docs/installation.md#ios-selbst-bauen) |
| Web | See the [installation guide](https://github.com/CodefrogCF/AstroManager/blob/main/docs/installation.md#choose-a-platform) for browser requirements and self-hosting. |

If you used a development build, export an `.ambackup` before updating.
Compare the SHA-256 digest of your download with the release checksums.
Fresh weather, terrain downloads and sky imagery require an internet
connection. For the interactive Sky Atlas on Windows, use the Web build.
