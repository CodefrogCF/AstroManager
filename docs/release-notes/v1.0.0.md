# AstroManager v1.0.0

AstroManager is an offline-first tool for planning astrophotography sessions.
The first stable release brings together an offline target catalog,
site-based astronomical calculations, camera framing, night planning,
imaging projects and observation logs.

## Highlights

- Customize the Dashboard with finer widget sizes and drag-and-drop ordering.
  Widget positions and sizes are saved for each screen class.
- Refresh weather from the Dashboard. Successful updates are shared with
  recommendations for the same site and covered time window. The weather
  widget shows clear-sky periods for astronomical darkness or the full site-local day.
- Recommendations consider forecast cloud cover, target visibility, Moon
  conditions and your manually recorded Bortle class. Fresh forecasts of 100%
  cloud cover split usable periods. Missing forecasts yield provisional scores.
- Select an object directly in the Sky Atlas, open its catalog details and
  see the current field of view while zooming. Camera footprints appear in
  Detail and Sky Dome modes.
- Schedule a project target in the Night Planner, then edit or remove its
  time block from the night overview.
- Save a terrain horizon where the elevation source has coverage and reuse its
  profile offline. Export and restore portable `.ambackup` files, including
  session images when selected.

## Install and upgrade

Download the package for your platform and compare its SHA-256 digest with
the release checksums. Export a backup from your existing installation
before updating. Keep the file in a private location. A signed Android update
uses the same signing key as the installed release.

The Windows download is a portable x64 archive. Extract it in full before
running `astromanager.exe`. The Web archive contains a deployable static site.
See the installation guide for platform requirements and the release page for
available Web and Apple distribution links.

## Known limitations

- The embedded atlas requires WebGL and online imagery. On native Windows,
  use the Web app for the interactive atlas.
- Opportunity alerts are available on Android and iOS. Checks run on launch,
  foreground return or manual request.
- Weather and terrain are estimates. Terrain coverage varies by location,
  and profiles omit objects such as trees and buildings. Web reloads depend
  on the deployment and browser cache.
- Backups are unencrypted local files. Export one before clearing app or
  browser storage.
